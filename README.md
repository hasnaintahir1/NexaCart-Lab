# Nexa Cart Lab

Hi my name is Hasnain. 

**What I Built**: I built a Shopify app named **Nexa Cart Lab** using React, Node.js, and MongoDB. This app helps to track product updates and save them into the database in real time.

**Issues and Solutions**: While making this project, I faced some issues with the database connection and webhook testing. The local server was not catching the test events properly at first. I solved this by fixing the network routes and using the Shopify CLI tool correctly to trigger webhooks.

**What I Learned**: In this project, I learned how to use **Polaris** **Shopify Webhooks** and **GraphQL** queries to connect an online store with a custom backend and database.

I really enjoyed building this project and learning new Shopify development skills.
